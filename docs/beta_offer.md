# ベータ登録特典（2026-09-19 決定）

利用案内 /guide/ の料金説明はこの方針を正とする。過去の収益化ドラフトより優先。

- ベータ期間中は全機能無料。
- ベータ期間中に登録したサークルは、正式版提供開始から1年間も全機能無料。登録日から1年間ではない。
- 特典終了後も出欠、対戦表、スコア入力・当日結果は無料プランで利用可。
- 累計ランキング・個人戦績、データ出力・バックアップの継続利用は有料プランへの加入が必要。
- 有料料金、正式版開始日、募集終了日は未定。決まり次第案内する。

## 今回
利用案内とフッターリンク、サイトマップへの追加。課金や機能制限は追加していない。

## 有料化前に必要な実装
- 現在のClub.created_atを保持し、既存サークルを含む対象サークルの特典を移行時に確定する。
- 特典対象・正式版開始日・無料終了日を記録し、デモクラブは対象外にする。
- 対象の抽出、終了日の算出（暦で1年）、無料期間中の全機能利用をテストする。
- 無料期間終了後の有料加入手続きと機能制限を実装する。加入前に料金・条件を提示する。
- 決済情報のない既存サークルへ自動課金しない。
